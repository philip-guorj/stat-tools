# StatTools - 田间试验统计分析平台

StatTools 是一个基于 Streamlit 的农业田间试验数据分析工具，支持：

- 📈 描述统计、假设检验、方差分析
- 🔬 回归分析、多变量分析
- 📊 数据可视化
- 🧪 试验设计（完全随机、随机区组、裂区、Alpha、Lattice、增广、对角线等）
- 📋 区试报告自动生成

## 本地运行

```bash
pip install -r requirements.txt
streamlit run 数据管理.py
```
